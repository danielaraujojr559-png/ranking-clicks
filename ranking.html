1. Win32 RawInput API

Captura cliques diretamente do barramento do Windows através de RegisterRawInputDevices com a flag RIDEV_INPUTSINK. Zero impacto de performance e zero input lag.

2. Auto-Instalação Local

Ao iniciar na pasta Downloads, cria o diretório %LOCALAPPDATA%\MouseClickCounter, copia-se com segurança e registra o arranque automático no Registro do Windows.

3. Single Instance (Mutex)

Protegido por um CreateMutexW global exclusivo. Impede instâncias duplicadas e garante contagem de cliques 100% fidedigna.

4. Persistência Permanente

Os cliques locais são salvos em clicks.dat a cada 10 cliques e sincronizados a cada 60s com a base de dados Turso (libSQL Serverless).
