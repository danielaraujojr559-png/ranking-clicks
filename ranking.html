Engenharia do Projeto

Esta aplicação foi construída com uma arquitetura desenhada para garantir zero impacto no uso normal do computador.

O Motor (C++): Um executável a correr de forma 100% invisível em segundo plano, consumindo apenas ~10 MB de RAM.

Captura Raw Input: Em vez de utilizar mouse hooks tradicionais que causam input lag ou interferem com outros softwares, o programa lê diretamente os dados de hardware na raiz do sistema operativo, garantindo a máxima performance.

O Servidor (Node.js): Processa os dados de forma assíncrona, mantendo o ranking sempre atualizado.

Sincronização: Para poupar os recursos de rede, a comunicação ocorre apenas a cada 15 segundos, enviando um pacote JSON minúsculo para a web.
